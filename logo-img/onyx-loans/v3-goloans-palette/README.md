# Onyx Loans — v3 concepts (GoLoans palette)

Palette taken from GoLoans (`GOLOANS-NEWEST-FINAL-WEBSITE/style.css` + `goloans-logo.svg`):
green `#008D05`, deep green `#006B04`, light green `#3DAA36`, onyx black `#0B0F0D`, white.
"Onyx" is a black stone, so black + GoLoans green = the name *and* the family.

| Direction | Idea | Best for |
|---|---|---|
| **01 Sister Block** | Mirror of the GoLoans block lockup (GO green/LOANS black → ONYX black/LOANS green), forward slant + speed stripes. | Strongest family tie; ads, co-branding with GoLoans. |
| **02 Onyx Gem** | The O is a cut onyx; facets = transparent terms, stone = security/value, one green facet = "GO"/approval. Manrope wordmark. | Most premium & ownable; trust-led positioning. |
| **03 Split O** | Italic O split diagonally: onyx half = borrower, green half = cosigner/lender lifted forward. Also reads "CO" (cosign). | Best story for the matching service; GoLoans italic DNA. |

Each direction: `logo-horizontal`, `logo-reversed`, `logo-one-colour`, `mark`, `app-icon` (SVG master + PNG @2x), and `board-*.png`.
Regenerate: `python3 scripts/generate-onyx-logos-v3.py OUT_DIR FONT_DIR` (needs `@fontsource/barlow-condensed`, `@fontsource/manrope`, `cairosvg`, `fonttools`).
