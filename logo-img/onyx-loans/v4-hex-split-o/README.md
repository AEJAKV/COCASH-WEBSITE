# Onyx Loans — v4 "Hex Split O" (Direction 03 x segmented-hexagon reference)

GoLoans palette: green `#008D05`, orange `#FF7A00` (GoLoans accent), onyx `#0B0F0D`, white.

**The mark:** a hexagon O (a cut onyx crystal) in six segments.
- Lower half, onyx = the borrower, the solid base.
- Upper half, green, lifted up and forward = the cosigner / lender who lifts you.
- Orange rising segment = the "GO"; the same orange stroke rises through the X in the wordmark.
- Gaps at the corners = clear, transparent terms.

**Variations:** `v4a` mark + ONYX LOANS (italic caps, GoLoans DNA) · `v4b` the mark is the O ([O]NYX / LOANS) · `v4c` upright, friendly lowercase.
Each has `logo-horizontal`, `logo-reversed`, `logo-one-colour`; shared `onyx-v4-mark` and `onyx-v4-app-icon`. SVG master + PNG @2x.
Regenerate: `python3 scripts/generate-onyx-logos-v4.py OUT_DIR FONT_DIR`.
